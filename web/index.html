Panduan Instalasi

Ikuti langkah ini untuk menjalankan aplikasi di perangkat Anda.

1
Persiapan Lingkungan

Pastikan Anda telah menginstal Python 3.10 ke atas. Clone repository ini ke folder lokal Anda.

git clone https://github.com/abyfromheaven/FAST.git
2
Instalasi Dependensi

Install semua library yang dibutuhkan menggunakan pip melalui terminal atau CMD.

pip install -r requirements.txt
3
Menjalankan Aplikasi

Gunakan file run.py di root project untuk memulai aplikasi dengan benar.

python run.py
!
Penting: Training Model

Setelah aplikasi terbuka, masuk ke menu Rekam Wajah untuk mendaftarkan diri, lalu klik Latih Model. Fitur absensi tidak akan berfungsi sebelum langkah ini dilakukan.
